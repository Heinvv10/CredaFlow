## Purpose
ABSA bank-statement ingest + reconciliation: parse a CSV export, match
credits against active loans, and (once a human confirms) turn a match into
a `Payment` via the existing balance-recompute seam. See `lib/bank-sync/README.md`.

## Critical Rules
- **Money is integer cents.** `amountCents` is signed; `> 0` is a credit,
  `< 0` a debit (`lib/bank-sync/types.ts`, `lib/bank-sync/parse.ts`).
- **ABSA credentials NEVER touch the LMS/DB** — this module only receives an
  already-downloaded file (a staff manual upload).
- **`lib/bank-sync/import.ts` is the ONE money path.** Source-agnostic by
  design — it takes bytes, not a bank session. Add a source by CALLING
  `importStatement()`, never by re-implementing it; callers own only auth +
  error mapping. Its `actorEmail` is the audit identity (the real user for an
  upload) — never label a human as a service account.
- **`BankStatementImport`/`BankTransaction` are NOT in `TENANT_SCOPED_MODELS`**
  (`lib/tenant-scope.ts`) — every Prisma query on them MUST pass an explicit
  `where: { tenantId }` by hand.
- **`lib/bank-sync/apply.ts` deliberately mirrors** the payment `$transaction`
  in `app/api/payments/route.ts` (convention match). Don't extract a shared
  helper without doing that refactor repo-wide.
- **Parser is fail-loud on `Date`/`Amount` only** — a bad value throws and
  the import fails before persisting anything; `Balance` degrades to
  `null` on a bad value (informational only).
- **Auto-apply is OFF by default** (`TenantConfig.absaAutoApplyHighConfidence`).
  Best-effort even when on — a guard failure in `apply.ts` leaves the row
  `PROPOSED`, never a silent skip. All reconcile actions audit via `lib/audit.ts`.
- **The matcher never guesses.** `lib/bank-sync/reconcile.ts` only returns a
  tier for exactly one qualifying candidate; 0 or 2+ falls to `NONE` → review.

## Key Files
| File | Purpose |
|------|---------|
| `lib/bank-sync/parse.ts` | CSV → `ParsedStatementLine[]` |
| `lib/bank-sync/candidates.ts` | Active/defaulted loans → `CandidateLoan[]` |
| `lib/bank-sync/reconcile.ts` | Tiered matcher (EXACT/HEURISTIC/WEAK/NONE) |
| `lib/bank-sync/ingest.ts` | Persists matched lines, deduped via `lib/bank-sync/dedup.ts` |
| `lib/bank-sync/apply.ts` | Confirms a match → creates `Payment`, updates loan |
| `lib/bank-sync/import.ts` | **The pipeline** — parse→match→persist→audit, shared by every source |

## Dependencies
- **Internal:** `@/lib/audit`, `@/lib/prisma`, `@/lib/loan/balances`. **External:** none — there is no bank scraper.

## Common Tasks
| Task | Pattern |
|------|---------|
| Confirm a proposed match | `applyBankTransaction({ txnId, loanId, tenantId, userId, userEmail })` |
| Ignore a transaction | `ignoreBankTransaction({ txnId, tenantId, userId, userEmail, reason })` |
| Ingest a statement from any source | `importStatement({ tenantId, raw, actorEmail, … })` |
