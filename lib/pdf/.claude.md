## Purpose
Generates NCA-compliant PDF documents (credit agreements, Section 129
notices, debit mandates, certificates of balance, statements) using `pdf-lib`.
The output is the legal artefact a court would read.

## Critical Rules
- **NCA wording is verbatim.** Section 129 notice and credit-agreement
  clauses are mandated by statute. Never paraphrase, summarise, or
  "improve" the language. If the legal team has not approved a wording
  change, do not ship it.
- **Lender identity comes in as `lender: Pick<LenderIdentity, …>`** (from
  `getLenderIdentity`, `lib/config/identity.ts`) and each generator re-checks
  the fields it prints with `requireLenderIdentityFields`, which throws
  `LenderIdentityError`. Never hardcode a name, number, office or contact,
  and never default one: a missing identity refuses the document.
- **Logo is an input.** `logo` (PNG bytes) is optional; without it the
  text header prints. Routes pass the tenant's upload (`getLenderLogo`,
  `lib/config/lender-logo.ts`); size it with `fitLogo` so it never covers
  text. Re-rendered drafts (the application debit mandate) pass none.
- **All money is `formatZarPdf()`.** No bare numbers, no other locale.
- **All dates are `formatDatePdf()`.** Consistent format across documents.
- **Tables continue onto a new page, never break** (`drawRowsWithContinuation`):
  repeat the existing title and headers, no new wording, one TOTAL after the
  last row. Tables that fit keep their pinned bytes (`lib/pdf/schedule-continuation.test.ts`).
- **Helpers are shared.** New colors, fonts, or table primitives go in
  `lib/pdf/helpers.ts` — don't redefine `A4_WIDTH`/`MARGIN` per file.

## Key Files
| File | Purpose |
|------|---------|
| `lib/pdf/helpers.ts` | Page constants, colors, font loaders, draw primitives |
| `lib/pdf/creditAgreement.ts` | NCA credit agreement (`renderCreditAgreement`) |
| `lib/pdf/section129.ts` | Section 129 notice of default |
| `lib/pdf/debitMandate.ts` | Stitch debit-order mandate |
| `lib/pdf/certificateOfBalance.ts` | Certificate of balance for legal handover |
| `lib/pdf/statement.ts` | Loan statement (running balance) |

## Dependencies
- **External:** `pdf-lib`
- **Internal:** `@/lib/loan-calculator` (for `LoanCalcResult` shape)

## Common Tasks
| Task | Pattern |
|------|---------|
| Render credit agreement | `generateCreditAgreementPdf({ variant, lender, client, application, calc, … })` |
| Render Section 129 | `generateSection129Pdf({ lender, client, loan, noticeDate })` |
| Add a new doc type | Copy an existing file, reuse helpers, add legal review before merge |
