# Module: statement-analysis
<!-- Keep under 50 lines - reference, don't duplicate -->

## Purpose
Reads a BANK_STATEMENT ClientDocument down to its transactions and persists
one `StatementAnalysis` per (bytes, `PARSER_VERSION`). The credit checks
(`lib/credit-checks/`) consume it. Pipeline: `analyse.ts`.

## Critical Rules
- **The balance check is the oracle.** opening + Σ amounts = closing (±1c), and
  each printed running balance = previous + amount (`balance-check.ts`). A
  reader change is only right if bank-produced corpus files still PASS.
- **Text readers for Capitec (`capitec.ts`) and FNB (`fnb.ts`) only.** Every
  other bank, scans and photos go to the vision reader (`vlm-reader.ts`).
- **A vision read is never tamper evidence.** Its balance FAIL becomes
  MANUAL_REVIEW/UNVERIFIED_READ, never BALANCE_MISMATCH: a misread and a
  forgery look the same.
- **Never call the vision reader inside a staff request.** `persist.ts`
  `allowVlm: false` defers it; the upload/re-extract path reads in background.
- **Bump `PARSER_VERSION`** when a reader returns something different for the
  same bytes, so stored reads are re-made rather than trusted.
- **pdfinfo fields parse with `[ \t]*`**, not `\s*`: an empty `Creator:` would
  otherwise read the next line (every Capitec original has none).
- **FNB marks only credits** ("Cr"); an unmarked amount or balance is a debit /
  overdrawn. "EDO Collection Attempt" rows print an amount but move no money
  (`nonPosting`). FNB rows are read from word boxes (`pdftotext -bbox`): its
  proportional font makes `-layout` columns drift.
- **Intake decryption rewrites the file** (`lib/documents/pdf-decrypt.ts`),
  erasing appended revisions: the upload route records the original's count
  on the DOCUMENT_DECRYPTED_AT_INTAKE audit row and `persist.ts` reads it.
- **A read that fails is persisted** as UNREADABLE (signal READ_FAILED), never
  thrown into a staff request; it is not retried until `PARSER_VERSION` moves.
- **Hostile-file bounds:** poppler runs async, pdfinfo before any text pass,
  text only up to `TEXT_MAX_PAGES`, Capitec lines over 400 chars skipped,
  amounts above `MAX_CENTS` refused, implausible periods dropped, duplicate
  pdfinfo fields distrusted (METADATA_AMBIGUOUS), one background vision read
  at a time per process.

## Corpus (real client data)
- Off-repo at `STATEMENT_CORPUS_DIR`; runner in `accuracy/` (README there).
- Never commit, print or log names, ID/account numbers or transaction text
  from it; never send it to any model but the local one at `VLM_API_URL`.
- Inspect layouts only through scripts that print masked shapes (a/9) or counts.
- Corpus vision runs only outside 08:00–17:00 SAST on weekdays (shared model).

## Fixtures
`fixtures/` builds synthetic Capitec/FNB-like PDFs (`synthetic.ts`, `dataset.ts`)
and doctored variants (`doctor.ts`). All values invented ("T TESTER").
