## Purpose
Per-lender staff policies: two-factor (`staff-totp-policy.ts`), and access
restrictions — SAST working hours and a CIDR IP allowlist
(`staff-access-*.ts`), checked at sign-in and on every node-side session read.

## Critical Rules
- **The IP allowlist is only as strong as the proxy.** The caller's address is
  `callerIp()` (`lib/rate-limit.ts`): the X-Forwarded-For hop that
  `TRUSTED_PROXY` trusted proxies appended. When `TRUSTED_PROXY` is set, the
  app port must NOT be reachable except through those proxies — a client that
  reaches the app directly can write any X-Forwarded-For and pass the
  allowlist. Bind the container to the proxy network or firewall the port.
- **No trusted proxy, no allowlist.** With `TRUSTED_PROXY` unset every caller
  is "unknown": the settings route refuses to save an allowlist, and a stored
  one refuses every non-Super-Admin.
- **A SUPER_ADMIN is never refused, always audited** (`STAFF_ACCESS_BYPASSED`).
- **A refusal mid-session ends the session** like a tokenVersion revocation;
  the policy rides on `revalidatePrincipal`'s query, so it costs no round trip.
- **Fail closed** on a stored policy that does not parse (`policy_invalid`).
